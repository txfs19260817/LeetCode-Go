# Integration Requests Replay

You are given a list of HTTP request records captured from an integration.
Each record includes the URL path, headers, method, and body. Reconstruct and
replay each request against a base URL, then parse the JSON response.

> "We have a sequence of 5 API requests. The first two return a 200 OK status, but the following three are failing. Can you debug this and modify the requests so that they all succeed?"
> 
> "The issue stems from a hardcoded ID. The subsequent requests rely on the ID generated by the first request, but they are currently using a static value. How would you extract the dynamic ID from the first response and propagate it to the rest of the chain?"
> 
> "You need to replace the hardcoded ID with the correct runtime ID in both the Request URLs and the Request Bodies. Can you write the logic to swap these values before the requests are sent?"

## Input

- `requests`: list of request objects:
  - `url`, `headers`, `method`, `body`.
- `base_url`: base server URL.

## Output

- For each request, print or return the status code and parsed JSON response.

## Example

**Request**
```
{
  "url": "/v1/charges",
  "method": "POST",
  "body": "amount=123&currency=usd"
}
```

**Output**
```
status = 200
body = { ... }
```

## Constraints

- Methods are `GET` or `POST`.
- Body is `application/x-www-form-urlencoded`.
