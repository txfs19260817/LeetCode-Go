# Merge Failure Paths

## 题目描述
每条失败记录是一个层级路径（以 `,` 分隔），例如：
- `organization`
- `organization,site`
- `organization,site,camera`

如果某个上层路径已失败，则其所有下层路径都是冗余，应被移除。输出去冗余后的路径集合。

## 解法思路
本目录提供两种等价实现：
- 排序法（推荐复习主线）：排序后线性扫描，利用“父路径一定在子路径前”的性质去重。
- Trie 法：将路径插入前缀树；若父节点已终止则直接剪枝。

## 算法步骤
1. 先统一解析输入：
   - 按分隔符切分
   - 去除每段首尾空格
   - 过滤空段
2. 排序法：
   - 路径字典序排序
   - 维护结果列表 `merged`
   - 若当前路径是 `merged[-1]` 的后代前缀，则跳过，否则加入
3. Trie 法：
   - 插入路径时若遇到终止节点，说明已被父路径覆盖，直接返回
   - 插入结束将当前节点标记终止并清空子节点（删除冗余后代）
   - DFS 收集终止节点得到答案

## 复杂度分析
- 设路径数为 `N`，平均段数为 `L`。
- 排序法：`O(N log N * L)`，扫描部分 `O(N * L)`。
- Trie 法：构建和收集近似 `O(total_segments)`，外加输出排序需求（实现中对 children 做了排序以保证稳定输出）。

## 边界与易错点
- 输入可能有重复路径，结果应自然去重。
- 输入可能包含多余空格或空段，解析时需清洗。
- 需要保证输出稳定（与插入顺序无关），因此收集阶段建议排序。
- 判断“父路径”应基于段级前缀，而不是字符串前缀。

## 示例
```text
Input:
["o1,s1,c1", "o1,s1", "o1,s2,c1"]

Output:
["o1,s1", "o1,s2,c1"]
```
