# Document Query Collapse

系统中有两类对象：

- 文件 `Document`
- 查询指令 `Query`

它们之间存在包含关系：

- 一个文件包含多个查询指令
- 一个查询指令也可以出现在多个文件中

损坏传播规则如下：

1. 初始有一部分查询指令已经损坏
2. 如果一个文件中包含任意一个损坏的查询指令，那么这个文件也会损坏
3. 一旦一个文件损坏，该文件中包含的所有查询指令都会损坏
4. 上述过程会持续传播，直到没有新的文件或查询指令继续损坏

目标：给定所有文件的包含关系和初始损坏查询指令列表，返回最终所有损坏的文件列表。

## Example
**Input:**
```text
doc_to_queries = {
    "Doc1": ["Q1", "Q2"],
    "Doc2": ["Q2", "Q3"],
    "Doc3": ["Q4", "Q5"],
}
collapsed_queries = ["Q1"]
```

**Output:**
```text
["Doc1", "Doc2"]
```

解释：

1. `Q1` 坏了，所以包含它的 `Doc1` 坏了
2. `Doc1` 坏了，于是它包含的 `Q2` 也坏了
3. `Q2` 坏了，所以 `Doc2` 也坏了
4. `Doc2` 坏了，于是 `Q3` 也坏了
5. `Doc3` 与这些损坏没有连接，所以保持安全
