# KNN Clustering

给定一组带标签的二维点，使用 KNN（k-nearest neighbors）为查询点分配簇标签。

规则：
- 距离使用欧式距离的平方（避免开方）
- 对每个查询点，取最近的 `k` 个训练点做多数投票
- 若票数相同，选择总距离更小的标签
- 若票数和总距离都相同，选择标签值更小的标签
- 当 `k <= 0` 或训练集为空时，返回 `-1`

## Example
**Input:**
```
train = [((0,0),0), ((0,1),0), ((10,10),1), ((10,11),1)]
queries = [(0.2,0.1), (9.8,10.2), (5,5)]
k = 3
```

**Output:**
```
[0, 1, 0]
```
